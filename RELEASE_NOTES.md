Первый релиз Quay Store: sideload-стор, который подписывает и ставит приложения прямо на iPhone, без компьютера.

- Источники AltStore / SideStore (Feather, ESign) и репозитории GitHub с .ipa в релизах
- Подпись бесплатным Apple ID (7 дней, продление кнопкой, в фоне и через «Команды») или своим сертификатом
- Свой сертификат ставит приложения через itms-services: без LocalDevVPN и pairing file
- Pairing file прямо на iPhone (iOS 27+), поддержка RPPairing для iOS 26.4+
- Несколько Apple ID и сертификатов, экспорт сертификата Apple ID в .p12
- Твики: встраивание .dylib перед подписью
- Обновления: новая версия или пересобранный файл, уведомления
- Логи установки, тема и цвет акцента, экспорт и импорт настроек
