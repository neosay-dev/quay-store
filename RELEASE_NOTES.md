Первая версия Quay Store.

- Источники в формате AltStore / SideStore и репозитории GitHub
- Подпись бесплатным Apple ID (7 дней, продление) или своим сертификатом
- Установка без компьютера через LocalDevVPN и pairing file
- Обновления: новая версия или пересобранный файл, уведомления
- Действия для «Команд»: «Обновить подписи», «Проверить обновления»
